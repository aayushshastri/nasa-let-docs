    setupDAQ.py

    This script initializes and configures a DAQ (Data Acquisition) task using NI-DAQmx in Python.

    ```python

    ============================================

    1. Channel Configuration

    ============================================

    Adds a voltage input channel (AI0) to the task with a ±10V range.

    This is where we tell the DAQ which physical channel to read from.

    task.ai_channels.add_ai_voltage_chan("Dev1/ai0", min_val=-10.0, max_val=10.0)

    ============================================

    2. Clock & Sampling Rate

    ============================================

    Configures the sample clock for the task.

    It sets the sampling rate to 1000 samples per second (1 kHz),

    and uses a continuous acquisition mode for ongoing data collection.

    task.timing.cfg_samp_clk_timing( rate=1000, sample_mode=nidaqmx.constants.AcquisitionType.CONTINUOUS )

    ============================================

    3. Start & Stop the Task

    ============================================

    Starts the DAQ task to begin data acquisition.

    task.start()

    Data would typically be read here in a loop or processing function.

    Stops the task after acquisition is complete.

    task.stop()

    Properly closes and releases all DAQ resources.

    task.close()

    ============================================

    Output Summary

    ============================================

    - The DAQ system is initialized

    - The analog input channel is defined

    - Sampling rate is configured

    - Task is started and stopped cleanly

    - The system is ready for integration with data logging
