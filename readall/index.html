    readall.py¶

    # readall.py
    # This script handles automated multi-channel acquisition using NI-DAQmx and logs data to CSV.

    This script handles automated multi-channel acquisition using NI-DAQmx and logs data to CSV.

    Imports¶

    import nidaqmx
    from nidaqmx.constants import AcquisitionType
    from nidaqmx.stream_readers import AnalogMultiChannelReader
    import numpy as np
    import csv
    import time

    Import required modules for DAQ operations, data handling, and timing.

    Setup¶

    duration = 10
    sampling_rate = 1000
    channel_range = (-10.0, 10.0)

    Set total test duration, sample rate, and input voltage range.

    Channel Detection and Configuration¶

    task = nidaqmx.Task()
    device = nidaqmx.system.Device("Dev1")

    for channel in device.ai_physical_chans.channel_names:
        task.ai_channels.add_ai_voltage_chan(channel, min_val=channel_range[0], max_val=channel_range[1])

    Detect all AI channels on Dev1 and add them to the task with proper voltage range.

    Clock & Timing Configuration¶

    task.timing.cfg_samp_clk_timing(
        rate=sampling_rate,
        sample_mode=AcquisitionType.CONTINUOUS
    )

    Configure the DAQ task for continuous acquisition at the set sampling rate.

    Data Acquisition Preparation¶

    num_channels = len(device.ai_physical_chans.channel_names)
    samples_per_read = int(sampling_rate * duration / 10)
    buffer = np.zeros((num_channels, samples_per_read), dtype=np.float64)

    Preallocate a buffer to hold sample data from all channels.

    reader = AnalogMultiChannelReader(task.in_stream)

    Initialize the stream reader to manage multi-channel data reading.

    Start Task and Read Loop¶

    task.start()
    start_time = time.time()

    Begin data acquisition and track the test duration.

    with open("readout.csv", "w", newline="") as csvfile:
        writer = csv.writer(csvfile)
        while time.time() - start_time < duration:
            reader.read_many_sample(buffer, number_of_samples_per_channel=samples_per_read, timeout=5.0)
            for row in buffer.T:
                writer.writerow(row)

    Stream data in chunks, transpose it, and write each row into a CSV file.

    task.stop()
    task.close()

    Stop and clean up the task after the acquisition loop ends.

    Output¶

    # A CSV file called "readout.csv" will be created with one row per sample.
    # Each column in the CSV represents one channel's reading at that time slice.

    Output is a readout.csv file with time-synced multichannel data.
