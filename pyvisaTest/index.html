    pyvisaTest.py¶

    # pyvisaTest.py
    # This script initializes and communicates with an instrument over VISA using PyVISA.

    This script initializes and communicates with an instrument over VISA using PyVISA.

    Imports¶

    import pyvisa

    Import the PyVISA library and initialize a resource manager.

    Setup Resource Manager¶

    rm = pyvisa.ResourceManager()

    Create a ResourceManager object to detect available VISA instruments.

    Instrument Discovery¶

    instruments = rm.list_resources()
    print("Connected instruments:", instruments)

    List all connected VISA instruments.

    Connect to Instrument¶

    inst = rm.open_resource(instruments[0])

    Open a session to the first instrument. (You can also specify an exact address manually.)

    Communication Settings¶

    inst.timeout = 5000
    inst.write_termination = '\n'
    inst.read_termination = '\n'

    Optional: Set timeouts and termination characters for communication.

    Write to Instrument¶

    inst.write("*IDN?")

    Send a standard identification query (*IDN?) to the instrument.

    Read Response¶

    response = inst.read()
    print("Instrument ID:", response)

    Read and print the device's response.

    Clean Up¶

    inst.close()

    Close the instrument session when done.
